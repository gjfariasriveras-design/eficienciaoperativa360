Prompt 1 · Filtrar CVs y construir shortlist

Útil para selección de personal cuando se necesita ordenar candidatos con un criterio más objetivo.

Prompt listo
Actúa como analista senior de selección. Voy a compartir varias hojas de vida para el cargo de [NOMBRE DEL CARGO]. Evalúalas con base en estos criterios: [EXPERIENCIA CLAVE], [FORMACIÓN], [HABILIDADES], [SECTOR], [NIVEL DE RESPONSABILIDAD].

Necesito que entregues:
1. Ranking del 1 al 5 o del 1 al 10, según cantidad de candidatos.
2. Tabla comparativa con fortalezas, brechas y nivel de ajuste.
3. Recomendación de shortlist final.
4. Resumen ejecutivo para presentar a gerencia en lenguaje claro.
5. Riesgos o dudas que deben validarse en entrevista.

No inventes información. Si algo no está en el CV, indícalo como no evidenciado.

Prompt 2 · Seguimiento y trazabilidad administrativa

Útil para convertir pendientes dispersos en un tablero de control práctico.

Prompt listo
Actúa como coordinador ejecutivo de control administrativo. Te voy a compartir una lista de pendientes, avances y problemas de distintas áreas. Organiza la información en una matriz con estas columnas: actividad, responsable, fecha compromiso, estado, riesgo, siguiente acción y comentario ejecutivo.

Luego entrega:
1. Prioridades de la semana.
2. Pendientes atrasados.
3. Riesgos críticos.
4. Resumen ejecutivo de 5 líneas para gerencia.

Quiero una salida clara, accionable y sin relleno.

Prompt 3 · Formatos, políticas y procedimientos

Útil cuando se necesita estructurar documentación interna con mejor lógica desde la primera versión.

Prompt listo
Actúa como consultor de estructura documental. Necesito redactar un [POLÍTICA / PROCEDIMIENTO / INSTRUCTIVO / FORMATO] sobre [TEMA].

Construye el documento con esta estructura:
- Objetivo
- Alcance
- Responsables
- Definiciones clave
- Desarrollo / pasos
- Controles
- Registros o evidencias
- Riesgos frecuentes
- Recomendaciones de implementación

Usa lenguaje corporativo claro, práctico y fácil de aplicar en una empresa mediana. No redactes de forma académica ni excesivamente legal.

Prompt 4 · Reporte ejecutivo

Útil para transformar información operativa en una lectura que sirva para decidir.

Prompt listo
Actúa como analista ejecutivo. Con la siguiente información operativa, redacta un reporte ejecutivo breve para gerencia.

Necesito:
1. Resumen de situación actual.
2. Principales hallazgos.
3. Riesgos o alertas críticas.
4. Recomendaciones inmediatas.
5. Próximos pasos sugeridos.

El tono debe ser gerencial, claro y orientado a decisión. No uses párrafos largos ni lenguaje ambiguo.
